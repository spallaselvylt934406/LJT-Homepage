# LJT-Homepage

Personal homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Pages

- About: `/`
- Publications: `/publications/`
- CV: `/cv/`

## Local development

```sh
bundle install
bundle exec jekyll serve
```

The site configuration is in `_config.yml`. Page content is in `_pages/`.
